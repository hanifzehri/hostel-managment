# 🏢 Royal Hostel Khuzdar - Management System Full-Stack

A complete, production-grade **Hostel Management System** built with **React 19**, **Tailwind CSS**, **Node.js/Express**, and **MongoDB / Mongoose**.

---

## ⚡ Quick Start

You can run commands directly from this root directory:

### Start Development Server (Full-Stack)
```bash
npm run dev
```
Starts both Backend API (`http://localhost:5000`) and Frontend Vite (`http://localhost:5173`).

### Or 1-Click Launch on Windows:
Double-click `Launch-Hostel-System.bat` in this folder.

### Other Useful Commands:
- `npm run dev:backend` - Run backend server only
- `npm run dev:frontend` - Run frontend Vite client only
- `npm run test` - Run full end-to-end integration test suite
- `npm run build` - Build production frontend bundle
- `npm run seed` - Re-seed database with demo records
